# **FDE Accelerator Track: Day 1 Student Practice Guide**

### **Project:** SupportDesk Frontend Development & Git Workflow

---

## **📍 Where Will Students Practice & What Platforms Are Used?**

Students will complete all practical work **locally on their own laptops/machines** using the following industry-standard development platforms:

1. **Code Editor & Terminal:** **Visual Studio Code (VS Code)** (Installed locally; used for writing all React code, running the terminal, and creating files).
2. **Runtime Environment:** **Node.js & npm** (Installed locally; runs the React development server via Vite).
3. **Version Control Platform:** **GitHub website & Git CLI** (Used for creating remote repositories, committing code, and pushing updates).
4. **Testing Platform:** **Web Browser** (Google Chrome, Brave, or Microsoft Edge; used to view the running app at `http://localhost:5173`).

## **Step-by-Step Execution Guide for Students**

---

### **Step 1: Plan and Setup (9:30 AM – 11:00 AM)**

#### **1.1 Create Your Project Checklist**

* **Where to do it:** Inside **VS Code** on your local machine.
* **What to do:** Create a text/markdown file to track what you need to code today so you stay organized.
* **How to do it (Step-by-Step):**
1. Open **VS Code** and open an empty folder or your terminal.
2. Create a new file named `TODO.md` in your project workspace.
3. Type or paste your feature checklist inside the file:
```markdown
# SupportDesk - Day 1 Checklist
- [ ] Create a navigation bar to switch between pages.
- [ ] Build a Ticket List page showing all support tickets.
- [ ] Build a Create Ticket form with input validation.
- [ ] Build a Ticket Detail page when clicking an individual ticket.

```


4. Save the file (`Ctrl + S` on Windows / `Cmd + S` on Mac).



#### **1.2 Initialize Your Code Repository**

* **Where to do it:** In the **VS Code Terminal** (local) and **GitHub.com** (remote).
* **What to do:** Initialize Git locally and link it to a new remote repository on GitHub.
* **How to do it (Step-by-Step):**
1. Open the integrated terminal in VS Code (`Ctrl + ~`).
2. Create your project folder and navigate inside it:
```bash
mkdir supportdesk-frontend
cd supportdesk-frontend

```


3. Initialize Git and stage your `TODO.md` file:
```bash
git init
git add TODO.md
git commit-m "Add Day 1 project checklist"

```


4. Go to **GitHub.com**, log in, and create a new empty repository named `supportdesk-frontend`.
5. Copy the repository URL provided by GitHub, then link it in your VS Code terminal and push your first commit:
```bash
git remote add origin <your-github-repo-url>
git branch -M main
git push -u origin main

```





---

### **Step 2: Initialize Project & Mock Data (11:15 AM – 1:00 PM)**

#### **2.1 Setup React with Vite**

* **Where to do it:** In the **VS Code Terminal**.
* **What to do:** Scaffold the React project and install routing/icon packages.
* **How to do it (Step-by-Step):**
1. Run the Vite setup command in your terminal:
```bash
npm create vite@latest . -- --template react

```


2. Install dependencies (React Router for page navigation and Lucide for icons):
```bash
npm install
npm install react-router-dom lucide-react

```


3. Start your local development server:
```bash
npm run dev

```


4. Open your **Web Browser** and navigate to `http://localhost:5173` to see your running app. *(Keep this terminal running!)*



#### **2.2 Create the Mock Data File**

* **Where to do it:** Inside **VS Code** (`src/` folder).
* **What to do:** Create a local mock data file so your frontend has tickets to display before the backend is built tomorrow.
* **How to do it (Step-by-Step):**
1. Inside the `src/` folder in VS Code, create a new file named `mockData.js`.
2. Paste the following sample data inside it and save:
```javascript
export const initialTickets = [
  {
    id: "TICK-101",
    title: "Cannot reset password",
    description: "Clicking the 'Forgot Password' link results in a 404 error page.",
    category: "Authentication",
    priority: "High",
    status: "Open",
  },
  {
    id: "TICK-102",
    title: "Billing invoice missing",
    description: "March invoice was not attached to the automated email statement.",
    category: "Billing",
    priority: "Medium",
    status: "In Progress",
  }
];

```





---

### **Step 3: Build Components & Routing (2:00 PM – 4:00 PM)**

* **Where to do it:** Inside **VS Code** by creating component files (`src/components/`).
* **What to do:** Build out the Navbar, Ticket List, Create Form, and Detail views.
* **How to do it (Step-by-Step):**
1. **Navbar (`src/components/Navbar.jsx`):** Build a header component with navigation links using React Router (`Link`).
2. **Ticket List (`src/components/TicketList.jsx`):** Import `initialTickets` from `mockData.js`, store them in state using `useState`, display them in cards, and add a status filter dropdown.
3. **Create Form (`src/components/CreateTicket.jsx`):** Build a controlled form using `useState` with input fields for Title, Category, Priority, and Description. Add validation to block empty submissions.
4. **Detail Page (`src/components/TicketDetail.jsx`):** Use `react-router-dom` dynamic routing (`/tickets/:id`) and `useParams()` to display full ticket info when clicked.



---

### **Step 4: Final Wrap-Up & Git Push (4:00 PM – 4:30 PM)**

* **Where to do it:** **Web Browser** (testing) and **VS Code Terminal** (pushing to GitHub).
* **What to do:** Test your completed local app in the browser and push your finished code to GitHub.
* **How to do it (Step-by-Step):**
1. Check your app in the browser (`http://localhost:5173`) to ensure navigation, form validation, and filters work correctly.
2. Open your VS Code terminal and push your final code to GitHub:
```bash
git add .
git commit -m "Completed Day 1 SupportDesk frontend implementation"
git push origin main

```

**Final Deliverable:** A fully working, interactive React frontend running locally on the student's machine in **VS Code / Chrome**, backed by a clean commit history on **GitHub**.
